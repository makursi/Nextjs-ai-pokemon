# Dark Mode - 亮暗模式支持

- **日期**: 2026-05-16
- **状态**: 已完成

---

## 概述

为 Choria 应用添加亮色/暗色主题切换功能，基于 `next-themes` 实现，支持跟随系统主题。

## 依赖

| 依赖          | 版本    | 用途                     |
| ------------- | ------- | ------------------------ |
| next-themes   | ^0.4.6  | 主题管理核心库           |
| lucide-react  | ^1.14.0 | 图标（Sun/Moon/Monitor） |
| dropdown-menu | shadcn  | 主题切换下拉菜单         |
| button        | shadcn  | 切换触发按钮             |

## 实现要点

### 1. CSS 变量方案

`globals.css` 已预先定义 `:root`（亮色）和 `.dark`（暗色）两套 CSS 自定义属性，通过切换 `<html>` 的 `class` 属性来控制主题。

### 2. class 策略

`ThemeProvider` 配置 `attribute="class"`，使得 next-themes 直接在 `<html>` 上添加/移除 `.dark` 类名，与现有 CSS 方案匹配。

### 3. 默认主题

`defaultTheme="system"` + `enableSystem`：首次访问时自动跟随操作系统主题偏好。

### 4. Hydration 处理

- `<html>` 添加 `suppressHydrationWarning`：避免 next-themes 在 hydration 前注入的 class 导致 React 报警
- `ModeToggle` 使用 `mounted` 状态：在客户端挂载前渲染占位按钮，避免图标闪烁和不匹配

### 5. 过渡动画

`disableTransitionOnChange`：切换主题时禁用 CSS transition，防止颜色渐变闪烁。

## 组件说明

### ThemeProvider (`src/components/theme-provider.tsx`)

客户端组件，封装 `next-themes` 的 `ThemeProvider`，配置：

- `attribute="class"` - 通过 class 切换主题
- `defaultTheme="system"` - 默认跟随系统
- `enableSystem` - 启用系统主题检测
- `disableTransitionOnChange` - 切换时禁用过渡

### ModeToggle (`src/components/mode-toggle.tsx`)

客户端组件，提供三种主题选项的切换按钮：

- **Light** - 亮色模式
- **Dark** - 暗色模式
- **System** - 跟随系统

使用 shadcn/ui 的 `DropdownMenu` 组件，按钮图标根据当前主题动态切换（亮色显示太阳，暗色显示月亮）。

## 使用方式

```tsx
// 在 layout.tsx 中包裹整个应用
<ThemeProvider>
  <QueryProvider>
    <main>{children}</main>
  </QueryProvider>
</ThemeProvider>

// 在任意页面中放置切换按钮
<ModeToggle />
```
